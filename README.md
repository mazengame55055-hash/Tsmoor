# 🎬 Kaggle Render Bot  (v1.3.0)

بوت Discord بيرندر ملفات Blender على **GPU مجاني من حساب Kaggle بتاع كل مستخدم**.
كل شخص بيسجّل توكين Kaggle بتاعه، فالرندر بيخصم من حصته هو مش من حسابك.

> الدليل ده لصاحب البوت (اللي بيشغّله). دليل المستخدمين في `USER_GUIDE.md` وتقدر تبعته لهم.

## 1) تجهيز بوت Discord
> ⚠️ **اعمل Application جديد مخصوص للبوت ده.** البوت بيستبدل كل الـ slash commands العامة للـ Application عند كل تشغيل، فلو استخدمت توكين بوت تاني عندك (زي بوت تذاكر) هتتمسح أوامره، ولو البوتين شغّالين مع بعض، الأوامر هتروح للغلط وتطلع "The application did not respond".

1. https://discord.com/developers/applications ← **New Application**.
2. تبويب **Bot** ← **Reset Token** وانسخ التوكين. مفيش Privileged Intents مطلوبة.
3. **OAuth2 ← URL Generator**: scopes `bot` + `applications.commands` (من غير Permissions) وضيف البوت لسيرفر.
4. **عشان زرار "Add to My Apps" يظهر** وتستخدم البوت في أي سيرفر أو خاص: من **Installation** فعّل **User Install** (وخلّي Install Link = Discord Provided Link، و Default Install Settings للـ User فيها scope `applications.commands`). بعد التشغيل بيتسجّل الأوامر بـ contexts: سيرفر + خاص + شات جماعي.

## 2) التشغيل
**Windows:** نزّل Python 3.10+ (علّم *Add to PATH*)، وبعدها دوس مرتين على **`run.bat`**.
أول مرة هيفتحلك `.env`: حط `DISCORD_TOKEN` واحفظ، وشغّل `run.bat` تاني. بيعيد تشغيل البوت لوحده لو وقع.

**Linux / VPS:** `./run.sh` (أو Docker: `docker compose up -d --build`).

**استضافة صغيرة (لوحة تحكم / Pterodactyl / ...):** ارفع الملفات، شغّل `pip install -r requirements.txt`، وأمر التشغيل `python main.py` (بايثون 3.10+).
حط `DISCORD_TOKEN` في متغيرات البيئة أو في ملف `.env`. تفاصيل المساحة الصغيرة (٥١٢ ميجا) تحت في قسم ٩.

لما تشوف `RenderBot v1.3.0 logged in as ...` يبقى شغّال. الأوامر ممكن تاخد كام دقيقة تظهر أول مرة.

## 3) ⚠️ لازم يفضل شغّال
البوت هو اللي بيتابع الرندرات ويبعت النتايج. لو اتقفل، الرندر بيكمّل على Kaggle، والنتيجة بتتبعت أول ما ترجّعه.
للاستخدام العام استضفه على VPS أو جهاز شغّال 24/7.

## 4) النسخ الاحتياطي (مهم)
فولدر **`data/`** فيه: قاعدة البيانات، ومفتاح التشفير `encryption.key`، واللوج `bot.log`.
**انسخه احتياطياً.** لو ضاع المفتاح، التوكينات المحفوظة متتفكش والكل يعمل `/login` من جديد.
متشاركش `data/` ولا `.env` مع حد.

## 5) الإعدادات (`.env`)
| متغير | معناه |
|---|---|
| `DISCORD_TOKEN` | **إجباري** |
| `ORIGINAL_FORCE_GPU` | `true` (افتراضي): Original يشغّل الـ GPU بس ومبيلمسش المشهد. `false` = صفر تدخل |
| `KAGGLE_ACCELERATOR` | نوع الـ GPU (`NvidiaTeslaT4`)، فاضي = الافتراضي عند Kaggle |
| `DISCORD_UPLOAD_LIMIT_MB` | أكبر نتيجة تتبعت كمرفق (الباقي رابط Kaggle) |
| `MAX_FILE_MB` / `MAX_FILES_PER_USER` | حدود الرفع (الافتراضي 100 ميجا و 50 ملف) |
| `UPLOAD_SLOTS` / `KAGGLE_LIGHT_SLOTS` / `KAGGLE_HEAVY_SLOTS` | عدد العمليات المتزامنة (للاستضافة الصغيرة) |
| `MIN_FREE_DISK_MB` | الرفع بيترفض لو هيفضل أقل من كده فاضي (60) |

## 6) التحديث
فك الإصدار الجديد فوق القديم **من غير ما تمسح `data/` ولا `.env`**، وشغّل `run.bat`.

## 7) لو فيه مشكلة
- **"The application did not respond" + في اللوج `Unknown interaction`**: الرد وصل Discord بعد مهلة الـ 3 ثواني. بص على سطر `interaction received ... age=` في اللوج: لو `age` كبير (أكتر من 2 ثانية) يبقى ساعة الجهاز غلط أو النت بطيء/VPN أو الجهاز مشغول. صحّح الساعة (Settings ← Time ← Sync now).
- **`DISCORD_TOKEN is missing`**: التوكين مش محفوظ في `.env` (من غير مسافات).
- **الأوامر مش ظاهرة**: استنى شوية وجرّب `Ctrl+R` في Discord.
- **مفيش رد في الخاص**: سيرفر مشترك أو User Install.
- **الرندر فشل**: البوت بيبعت السبب وآخر سطور اللوج. اللوج الكامل في `data/bot.log` وفي صفحة الرندر على Kaggle.
- **EEVEE بيعلّق**: خلّي المستخدم يشغّل **EEVEE→Cycles** (البوت بيقفل الرندر لوحده بعد 30 دقيقة صمت في EEVEE).

## 8) نبذة تقنية
- `bot/cogs/` الأوامر • `bot/kernel_job.py` السكريبت اللي بيشتغل **جوه Kaggle** (بيتولّد منه سكريبت لكل رندر).
- كل أمر Kaggle بيشتغل في عملية منفصلة بـ HOME فاضي، فالتوكينات مبتتخلطش وتوكين صاحب الجهاز مبيتسرّبش لحد.
- كل الأوامر Slash وبتشتغل في أي مكان (سيرفر/خاص/شات جماعي)، وكل الردود **ephemeral** (ليك إنت بس)، والنتيجة بتتبعت في **خاصك** دايماً لو الأمر اتكتب في سيرفر. ولها cooldown.

## 🚂 النشر على Railway
1. ارفع الكود على GitHub، وفي Railway: **New Project ← Deploy from GitHub repo** (بيستخدم الـ Dockerfile لوحده).
2. تبويب **Variables**: ضيف `DISCORD_TOKEN` (والباقي اختياري، راجع `.env.example`).
3. **مهم جداً — Volume:** كليك يمين على الـ canvas ← **Volume** ← اربطه بالسيرفس، و**Mount Path = `/app/data`**. من غيره كل إعادة تشغيل بتمسح التوكينات والملفات.
4. البوت مش بيحتاج Domain ولا Port (بيشتغل كـ worker).
5. خد نسخة احتياطية من الـ Volume من وقت للتاني (فيه مفتاح التشفير).

## 🗄️ النسخ الاحتياطي
- **تلقائي:** كل 24 ساعة (`BACKUP_INTERVAL_HOURS`) بيتحفظ ملف `.tar.gz` في `data/backups` (آخر 7)، ويتبعتلك في الخاص (`OWNER_ID`) **من غير مفتاح التشفير**.
- **يدوي:** `/backup` (للمالك بس). `include_key:True` بيضيف المفتاح للملف، فاحذفه بعد الحفظ.
- **المفتاح:** حطه كمتغير `ENCRYPTION_KEY` في Railway Variables واحتفظ بنسخة منه برا. النسخة من غير المفتاح مش هتفتح التوكينات.
- **الاسترجاع:** `/restore` (للمالك بس): ارفع ملف النسخة (`.tar.gz` من `/backup` أو `.sqlite3`) واختار `confirm: True`. البوت بيفحص الملف، ويتأكد إن مفتاح التشفير يفتح التوكينات، ويعمل **نسخة أمان** من البيانات الحالية، وبعدين يستبدلها. لو المفتاح مختلف بيرفض من غير ما يغيّر حاجة. (بديل يدوي: وقّف البوت وحط `bot.sqlite3` في `data/`.)

## ⚖️ مسؤولية
Kaggle ممكن يقيّد أو يمنع استخدام الـ GPU لأغراض غير تعلّم الآلة. راجع شروط Kaggle قبل ما تعلن البوت، وعرّف المستخدمين إن الاستخدام على مسؤوليتهم (الشرح موجود في `/help`).

## 9) استضافة صغيرة (٥١٢ ميجا مساحة)
- المكتبات (discord.py + kaggle + ...) بتاخد تقريباً **١٥٠–٢٥٠ ميجا** بعد التثبيت، فاتأكد إن الاستضافة تسمح بالتثبيت.
- الملفات بتتحمّل مؤقتاً على الديسك قبل ما تترفع لـ Kaggle ثم بتتمسح، علشان كده الحد الافتراضي **100 ميجا** للملف ورفع **واحد** في نفس الوقت. البوت بيرفض الرفع لو المساحة مش كفاية.
- نتيجة الرندر بتتنزّل بحد أقصى (`DISCORD_UPLOAD_LIMIT_MB` + 40 ميجا)؛ الأكبر من كده بيتبعتلك رابط Kaggle بدل ما يملا الديسك.
- فولدر `data/` صغير (قاعدة بيانات + مفتاح + لوج لحد ~8 ميجا).
- لو الرامات قليلة (256 ميجا) خلّي `KAGGLE_LIGHT_SLOTS=2`.
- أمر `/info` بيعرض وصف البوت واسم المطوّر وحساباته (غيّرها من أول `bot/cogs/general.py`).
